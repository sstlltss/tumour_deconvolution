# MethyLYZR

## Environment
To set up and activate the environment for data preparation and MethyLYZR, you might run the following command in `bash`:
```bash
conda install -f environment.yml -y
conda activate methylyzr
```

For training data, both of the following steps are required. For testing data, only Step 1 is necessary.

## Data Preparation: Training
Before generating the Feather matrix required by MethyLYZR, the extracted COV files must be organized into a sample-by-probe matrix. To enable cell type annotation during the subsequent processing steps, a TXT file contents the label of the samples must also be created. The expected format is shown below:
```
SRR10099840,DLBCL
SRR10099825,DLBCL
SRR11615800,GC
SRR11615880,GC
SRR3427332,PC
SRR3427335,PC
SRR10165874,normal
SRR10165875,normal
```
The first column contains the sample name, while the second column specifies the corresponding cell type (i.e., the cancer type or normal for normal cells). No header row is required. The name of the label file can be customized in `lyzr_data_preparation.py` as `LABEL_FILE`.

All samples listed should be placed in the same directory as the label file itself.  This directory should be specified as `INPUT_PATH` in the same script. The output location can be customized by modifying the `OUTPUT_PATH` variable in that script.

Once the COV files and the label file are prepared, run `lyzr_data_preparation.py` with the variable in the script `TEST_MODE=False` to get the input file for MethyLYZR training data preparation :
```
# set TEST_MODE = False
python lyzr_data_preparation.py
```

 In this mode, only probes present in more than half of the samples are retained. This threshold can be adjusted by modifying the `SITE_THRESHOLD_RATE` variable in the script. The number of retained probes will be reported after filtering. After probe filtering, samples containing too few retained probes are also removed. By default, the minimum number of required probes is 20k, which can be configured by modifying the `SAMPLE_THRESHOLD` variable in the script.

The output of `lyzr_data_preparation.py`(training mode) consists of three files:
- ClassID.csv
- merged_betas.feather
- merged_betas_with_NA.csv.gz

The first two files are the required as input of downstream pipeline. The last file is provided for data inspection and can also be used to rebuild the Feather file with different filtering thresholds.

## Training
Once `ClassID.csv` and `merged_betas.feather` are prepared, the mean beta can be generated by running `centroid_kernels.py`:
```
python centroid_kernels.py
```
The `OUTPUT_PATH` should beset to the same directory used in the previous step.

The script generates the mean beta matrix in Feather format: `mean.full.betas.feather`.

Next, the probe weight matrix can be calculated using `RELIEF_likeWeights.py`. The `INPUT_PATH` in this script should point to the same directory as the `OUTPUT_PATH` from the previous step:
```
python RELIEF_likeWeights.py
```
The script outputs the weight matrix in Feather format: `RELIEFF_allHits_k{N}centroids.feather`, where N=`NEAREST_CENTROID_NUM` (default=2) in `RELIEF_likeWeights.py`

The two files, `mean.full.betas.feather` and `RELIEFF_allHits_k{N}centroids.feather`, together constitute the pre-trained MethyLYZR model. Place both files in the `/model` directory for downstream pipeline execution.

## Data Preparation: Testing
For testing data, the COV and label file with the same format as training data is required.

In `lyzr_data_preparation.py`, set `TEST_MODE=True` to generate testing data. In this mode, each sample is saved as an individual Feather file after filtering. No probes or samples are removed; instead, all missing values (NA values) are discarded.
```
# set TEST_MODE = True
python lyzr_data_preparation.py
```

## Testing
### Prior Probability
In addition to `mean.full.betas.feather` and `RELIEFF_allHits_k{N}centroids.feather`, the model requires a third input file: `class_prior.csv`, which specifies the prior probability of each cell type and should be placed in `/model` as well.

The file must be in CSV format with a header row and two columns. The first column `Class` contains the names of the cell types, while the second column `Prior` specifies their corresponding prior probabilities. The file should use `,` as the field delimiter. An example is shown below:
```
Class,Prior
DLBCL,0.25
GC,0.25
PC,0.25
normal,0.25
```
If the prior probabilities of the cell types are unknown, it is recommended to assign equal probabilities to all classes.

### Run testing
Once the three model files (`mean.full.betas.feather`, `RELIEFF_allHits_k{N}centroids.feather`, and `class_prior.csv`) and the testing data have been prepared, the model is ready for inference.

Run `MethyLYZR_test.py` to start the prediction process. Set `INPUT_PATH` to the directory containing the testing files. The prediction results will be written to the directory specified by `OUTPUT_PATH`.

The output consists of the console output and a `prediction.csv` file saved in the output directory. An example of the console output for a single test sample is shown below:
```
-------------------------------------------------------
M e t h y L Y Z R
-------------------------------------------------------

Reading model from model/mean.full.betas.feather
                   model/RELIEFF_allHits_k2centroids.feather
                   model/class_priors.csv
-------------------------------------------------------
Sample: SAMPLE_NAME
-------------------------------------------------------

Loading data from testing/SAMPLE_NAME_betas.feather

Preprocessing data...
 - Filtering values...
 - Calculating noise...
Predicting classes...
```
Here is an example of `prediction.csv`:

| Class                                       | Prior                            | sample  | class  |
|---------------------------------------------|----------------------------------|---------|--------|
| {0: 'normal', 1: 'DLBCL', 2: 'GC', 3: 'PC'} | {0: 0.870, 1: 0.100, 2: 0.002, 3: 0.001} | sample1 | DLBCL  |
| {0: 'normal', 1: 'DLBCL', 2: 'GC', 3: 'PC'} | {0: 0.680, 1: 0.300, 2: 0.007, 3: 0.003} | sample2 | normal |
| {0: 'PC', 1: 'DLBCL', 2: 'GC', 3: 'normal'} | {0: 1.000, 1: 0.000, 2: 0.000, 3: 0.000} | sample3 | PC     |

The `Class` column lists the predicted cell types, and the `Prior` column shows the corresponding posterior probabilities. The predictions are sorted in descending order of probability. The `sample` and `class` columns indicate the sample name and its ground-truth cell type, respectively.
